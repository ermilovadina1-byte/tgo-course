# LoRA для оценки отзывов

Адаптер Qwen3-0.6B для предсказания оценки автора от 1 до 5 по русскоязычному отзыву об организации. Обучен на 5000 примерах mteb/GeoreviewClassification: по 1000 на класс, seed = 42, одна эпоха. Ранг LoRA равен 8, alpha = 16; адаптированы семь линейных проекций внимания и полносвязной сети. Обучаемых параметров 5 046 272.

Базовая модель закреплена на revision c1899de289a04d12100db370d81485cdf75e47ca. Адаптер загружается через PEFT 0.17.1; веса Qwen скачиваются отдельно. Для запроса используется шаблон из [prompting.py](../../prompting.py), размышления отключены, генерация жадная, не более трёх новых токенов. Полный облачный запуск описан в [корневом README](../../../README.md).

На первых 1000 отзывах test точность составила 0,580, macro-F1 0,5442, MAE 0,524 звезды. Слабее всего распознаётся оценка 2: 34 точных ответа из 196. Это результат одного эксперимента на отзывах; другие задачи и источники текстов не оценивались. [Отчёт](../../README.md) содержит сравнение с zero-shot и few-shot, параметры обучения и разбор ошибок.
