# pt01. Языковая модель и BPE

## Что сделано

Подготовка корпуса, биграммная модель, оценка перплексии, генерация и сравнение правдоподобия. Это промежуточный результат, не готовая работа для сдачи.

- `run.py` скачивает «Войну и мир» по ссылке из задания; повторно читает локальный `corpus.txt`.
- Текст приводится к нижнему регистру, «ё» заменяется на «е».
- Слова выделяются выражением `[а-я]+(?:-[а-я]+)*`. Пунктуация, цифры и латиница не входят в слова; внутренние дефисы сохраняются.
- Первые 90% слов предназначены для обучения, последние 10% для проверки. Порядок сохранен.
- Статистика всего корпуса записывается в `artifacts/corpus_stats.json`.
- `BigramModel.fit` считает слова и соседние пары только в обучающей части. `prob` использует сглаживание Лапласа, `logprob` суммирует натуральные логарифмы вероятностей настоящих продолжений.
- `perplexity` вычисляет `exp(-logprob / (число слов - 1))`. Первое проверочное слово служит контекстом и не оценивается; переход через границу обучения и проверки не учитывается.
- Результаты биграммной части записываются в `artifacts/bigram.json`; `artifacts/bigram_progress.json` сохраняется как актуальная копия для ссылок предыдущих шагов.
- Первые 12 слов проверки сравниваются с одной перестановкой при seed = 42 и alpha = 0.01. В `artifacts/likelihood.json` сохранены обе последовательности, счета пар и все 11 слагаемых для каждого варианта.
- `generate` строит шесть образцов по 30 слов, включая стартовое, для «князь» и «она» при T = 0.5, 1 и 2. Все образцы сохранены в `artifacts/generation.json` и `artifacts/bigram_progress.json`.
- Корпус исключен из Git через `pt01/.gitignore`.

Словарь модели содержит 45 309 обучающих слов и одну служебную категорию `<UNK>`: в нее попадают все слова, отсутствующие в обучении. Частоты проверочной части в модель не добавляются. Поэтому размер словаря для сглаживания равен 45 310, а не 48 117 (число разных слов во всей книге). В знаменателе учитывается число наблюдаемых продолжений контекста; последнее слово обучения не имеет следующего слова. Это сохраняет сумму вероятностей по словарю равной единице.

Запуск из корня проекта МТУСИ:

```sh
/opt/homebrew/bin/python3.12 pt01/run.py
/opt/homebrew/bin/python3.12 -m unittest discover -s pt01/tests -v
```

Python 3.11 или новее; для этого этапа достаточно стандартной библиотеки.
Путь к Python выше относится к текущему компьютеру.

Самые частые слова: «и» (21 085), «в» (10 870), «не» (8 520), «что» (7 600), «он» (7 395). Полные двадцать слов и первые двенадцать слов каждой части сохранены в JSON.

| Сглаживание alpha | Средняя отрицательная log-вероятность, нат | Перплексия |
|---|---:|---:|
| 1 | 9.664476 | 15 748.11 |
| 0.1 | 8.954615 | 7 743.54 |
| 0.01 | 8.577279 | 5 309.64 |

Лучший результат среди трех проверенных значений: alpha = 0.01. При alpha = 1 к каждой строке счетчиков добавляется суммарная масса 45 310, при alpha = 0.01 только 453.1. Большая добавка сильнее выравнивает вероятности и ослабляет найденные закономерности; в этом эксперименте это ухудшило предсказания.

После «князь» было 1 321 продолжение, из них «андрей» 775, «василий» 147, «багратион» 36. После «она» было 2 388 продолжений, самые частые: «не» 195, «была» 91, «с» 50. При alpha = 0.01 вероятность «андрей» после «князь» равна `(775 + 0.01) / (1321 + 0.01 * 45310)`, примерно 43.68%.

В проверочной части 3 496 вхождений незнакомых слов, 2 808 разных слов. Их оценка производится как одной категории `<UNK>`, а не как предсказание конкретного написания незнакомого слова.

Шестнадцать локальных тестов прошли: обработка текста, разделение, вероятности и перплексия по ручному расчету, сумма вероятностей, неизвестные слова, повторное обучение и некорректные входы. Перплексии дополнительно сверены независимым расчетом по частотам проверочных пар; расхождений в пределах относительной погрешности 1e-12 нет.

Генерация использует alpha = 0.01 и весь словарь модели, включая `<UNK>`. Ненаблюдавшиеся пары не исключаются. Температура применяется по формуле `P_T(w) = P(w) ** (1 / T) / sum(P(u) ** (1 / T))`; в коде эквивалентный устойчивый расчет через логарифмы. При T = 1 распределение совпадает с исходным.

Для каждого образца генератор случайных чисел отдельно начинает с seed = 42. Словарь отсортирован, поэтому порядок элементов не зависит от хеширования Python. При совпадении текущего слова на одном шаге дальнейшие хвосты двух образцов могут совпасть: одинаковы контекст и состояние генератора. Проверен повторный запуск из другой папки с другим `PYTHONHASHSEED`; JSON генерации совпал побайтно.

| T | P(андрей после князь) | Суммарная вероятность ненаблюдавшихся продолжений после князь |
|---|---:|---:|
| 0.5 | 95.90% | 0.0007% |
| 1 | 43.68% | 25.4321% |
| 2 | 0.58% | 94.1636% |

При T = 0.5 начало образца узнаваемо, но весь текст не сохраняет смысл. При T = 1 и 2 редкие слова быстро нарушают связность: сглаживание распределяет ненулевую вероятность по всему большому словарю, а повышение температуры усиливает суммарную массу редких вариантов. Низкая температура тоже не гарантирует связности, особенно после редкого контекста. Модель учитывает только одно предыдущее слово.

Температура дополнительно проверена на вероятностях 0.8 и 0.2 с ручным расчетом, на нормировке, нулевой вероятности и очень малой положительной температуре. Распределения для реальных контекстов «князь» и «административном» совпали с прямым возведением вероятностей в степень при всех трех температурах. Генерация не меняет обучающие счетчики и глобальный генератор случайных чисел.

Сравнение порядка слов (alpha = 0.01, seed = 42):

Исходный фрагмент:

> это был георгий й степени на другой день были у фельдмаршала обед

Перемешанный фрагмент:

> день на георгий были у другой обед й степени это был фельдмаршала

| Вариант | Сумма log P | Пар без наблюдений в обучении |
|---|---:|---:|
| Исходный | -83.142868 | 5 из 11 |
| Перемешанный | -94.891335 | 6 из 11 |

Большее значение log P означает более вероятное продолжение. Исходный порядок получил более высокую оценку: например, пара «другой день» встречалась 84 раза, а «другой обед» не встречалась. Это результат одной фиксированной перестановки, а не гарантия для любых перестановок. Первое слово каждого варианта не оценивается, сравниваются 11 условных вероятностей.

Фрагмент взят по заданию как первые 12 очищенных слов, а не отдельное предложение. В исходной книге здесь «Георгий 1-й степени»: после удаления цифр остается «й». Границы предложений также не сохраняются. Пять пар исходного фрагмента не встречались в обучении; без сглаживания уже одна такая пара дала бы нулевое произведение и log P = -inf.

Добавлены проверки сохранения набора слов с повторами, фиксированной длины и перестановки, суммы log P по ручному примеру и оценки незнакомых пар без изменения модели. На книге обе суммы дополнительно совпали с логарифмом прямого произведения 11 вероятностей.
