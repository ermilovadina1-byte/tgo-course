# Работа 1. Языковая модель из счетчиков и свой токенизатор

## Что сделано

На «Войне и мире» реализованы биграммная модель со сглаживанием Лапласа и собственный BPE на стандартном Python. Слова выделены по правилу задания: нижний регистр, «ё» заменена на «е», регулярное выражение `[а-я]+(?:-[а-я]+)*`. Биграмма обучена на первых 90% слов, последние 10% оставлены для проверки. BPE обучен на словах всего корпуса с частотой от 5: 1500 слияний, маркер конца слова `</w>`, применение правил по рангам.

## Что не получилось и почему

Связного текста на 30 слов не получилось: биграмма помнит только предыдущее слово. При T = 0.5 появляются привычные сочетания, но тема теряется; при T = 2 чаще выбираются редкие продолжения. У BPE частые слова становятся целыми токенами, а часть слов остается разбитой: 1500 слияний не покрывают все слова. Границы токенов определяются частотами пар и не обязаны совпадать с морфемами.
