# pt01. Языковая модель и BPE

## Что сделано

Собраны биграммная модель со сглаживанием, генерация с температурой, оценка перплексии и свой BPE. Python 3.11+, для вычислений только стандартная библиотека. Корпус скачивается автоматически; `corpus.txt` и окружение исключены из Git.

Биграммы обучены на первых 90% слов, проверены на последних 10%. Словарь: 45 309 обучающих слов + `<UNK>` для неизвестных. Счетчик контекста не включает последнее слово без продолжения. BPE по заданию обучен на всем корпусе: частоты не ниже 5, 9 002 разных слова; правила применены ко всем словам. При равенстве частот выбирается лексикографически первая пара.

Запуск из корня проекта (после создания окружения по командам ниже):

```sh
.venv/bin/python pt01/run.py --fast  # 200 слияний, перезаписывает bpe.json
.venv/bin/python pt01/run.py         # 1500 слияний, результат для сдачи
.venv/bin/python -m pytest tests/test_pt01.py pt01/tests -q
```

На другой машине: `python3 -m venv .venv`, затем `.venv/bin/python -m pip install -r pt01/requirements-dev.txt`. В `artifacts/` оставлен полный прогон.

## Что получилось

Корпус: 433 082 слова, 48 117 разных; обучение 389 773, проверка 43 309. При оценке 43 308 переходов. Двадцать частых слов во всем корпусе: и (21085); в (10870); не (8520); что (7600); он (7395); на (6665); с (5861); как (4011); его (3895); к (3428); я (2854); она (2732); но (2725); все (2674); было (2501); это (2434); то (2261); сказал (2000); так (1954); о (1832).

| alpha | Перплексия |
|---|---:|
| 1 | 15748.11 |
| 0.1 | 7743.54 |
| 0.01 | 5309.64 |

Лучшее из трех значений: alpha = 0.01. Большое сглаживание добавляет массу каждому слову большого словаря и сильнее выравнивает распределение, ослабляя наблюдаемые закономерности.

Генерация: alpha = 0.01, весь словарь без фильтрации, seed = 42 отдельно для каждого образца, 30 слов вместе со стартовым. При низкой температуре частые продолжения усиливаются, при высокой редкие варианты чаще нарушают связность.

T = 0.5:

> князь андрей был в котором он не только в отношении административном комочком наблюдала благороднее заперлась поверенного нерассчитанного братец ты не будет сказал он как будто спрашивая не было быть так

T = 2:

> князь посылаю берут изменники завернуто раненную приняли трепака возил небольшую бешенством жуя остановились бесполезным другую предполагалось переворотов заботливо подрагивающею смелость аниска слоном пропадаешь лавра гренадеров хозяйственные куражились воля восклицание стариковского

Исходный фрагмент: «это был георгий й степени на другой день были у фельдмаршала обед». Перемешанный: «день на георгий были у другой обед й степени это был фельдмаршала».

При alpha = 0.01: log P исходного -83.1429, перемешанного -94.8913; исходный выше. В исходном 5 ненаблюдавшихся пар из 11, без сглаживания log P был бы -inf. Первое слово не оценивается. «й» осталось от «1-й» после удаления цифр.

| BPE | Слияний | Словарь | Токенов | Токенов на слово | Символов / токенов | Весь запуск, с |
|---|---:|---:|---:|---:|---:|---:|
| Быстрый | 200 | 234 | 1363489 | 3.1483 | 1.6468 | 5.81 |
| Полный | 1500 | 1534 | 836977 | 1.9326 | 2.6827 | 14.03 |

Исходных символов в словах 2 245 342, без пробелов и маркеров конца. В числе BPE-токенов маркеры конца учитываются. Это сокращение длины последовательности, а не измерение размера файла в байтах. Полный BPE:

```text
наполеон -> [наполеон</w>]
сказала -> [сказала</w>]
неудовольствие -> [не] [удоволь] [ствие</w>]
```

Быстрый и полный режимы прошли по 8 неизмененных тестов преподавателя; дополнительно прошел 21 наш тест. Независимое применение сохраненных правил восстановило все 48 117 разных слов и подтвердило число токенов. Первые 200 слияний совпали между режимами. Доказательства и хеши исходных тестов: `artifacts/validation.json`.

## Что не получилось и почему

Генерация не сохраняет смысл длинного текста: биграмма учитывает только одно слово, а сглаживание дает массу множеству ненаблюдавшихся пар. Высокая температура усиливает этот эффект. Размер словаря BPE ограничен 1 500 слияниями, поэтому часть слов остается разбитой. Это ожидаемые ограничения моделей.
